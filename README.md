# LeetCode — Learning to Think in Code

A collection of my LeetCode solutions, mostly in Java, as I get better at data structures, algorithms, and problem-solving.

Some solutions came together on the first try. Some took way too long. A few made me question whether I knew how a `for` loop worked. I keep them here because each one taught me something.

## The Usual Process

```text
Read the problem
    ↓
"This looks easy"
    ↓
Write code
    ↓
Wrong Answer
    ↓
Find the one tiny mistake
    ↓
Accepted
    ↓
Feel like a genius
    ↓
Open the next problem
    ↓
"This looks impossible"
```

## What I'm Practicing

- Read the constraints and work through a small example by hand.
- Recognize the pattern and choose a data structure that fits.
- Check edge cases and reason about time and space complexity.
- Explain why the solution works in my own words.

Getting **Accepted** feels good. Being able to explain why the approach works is the part I want to get better at.

## One Rule

I give the problem a real try before reading someone else's solution. If I get stuck, I want to know where my reasoning broke down so I can spot the same mistake next time.

```java
while (!masteredDSA) {

}
```
